# 道東冬日自駕 · 共用旅行手帳

## 正式網站

已於 2026-10-06 上線至 Cloudflare：https://jp2026-doto-trip.annie54315431.workers.dev 。使用者持有的完整分享連結含金鑰，旅伴可查看與共同編輯，不需 ChatGPT 帳號。程式存於 GitHub，實際旅行資料存於 Cloudflare D1。下方 Python 啟動與共用說明僅適用本機版本；本機資料與雲端資料分開保存。

Cloudflare 更新方式請見 Cloudflare部署.md。這版尚未設定 GitHub 自動發布，更改程式後須重新部署，網站內修改旅行資料則直接儲存到 D1。

這是一個可持續編輯的旅行網頁專案。日期、航班、行程與預訂尚未填入，沒有假預訂或示範支出。

## 開啟

Windows 電腦雙擊「啟動旅行手帳.cmd」。啟動後自動開啟網頁，保留啟動視窗便可持續使用。程式需要 Python 3.10 以上；啟動檔會優先使用此電腦的內建執行環境，找不到時使用系統 Python。

也可執行 `python server.py --host 127.0.0.1 --port 8765`，開啟顯示的完整網址。

## 查看與共用

localhost 本機預覽僅限這台電腦；「分享旅行」複製本機網址不會讓外部旅伴連線。遠端共用請使用上方正式網站的完整分享連結。

同一 Wi-Fi 內共用：執行 `python server.py --host 0.0.0.0 --port 8765`，允許私人網路防火牆連線，把完整網址的 localhost 改為這台電腦的區域網路 IP。保留 `#key=...`，旅伴即可用手機開啟同一份資料；主機須保持運作。

跨網路分享：將此專案交給支援 Python 的主機，使用持久磁碟保存 data/，透過 HTTPS 反向代理對外提供網址。部署後才可使用真正的網路分享連結。這版沒有 Sites 發布識別或虛構的上線網址。

持有完整分享連結者可讀取及編輯。金鑰在網址片段中，API 以標頭驗證，不寫入請求日誌。分享連結請交給旅伴；不要放在公開社群。若需要撤銷連結，停止伺服器、刪除 data/access-key.txt 並重新啟動，分享新連結。

## 功能

- 每日行程時間軸、活動與日期上下移動、方案 A/B、當日備註。
- 地址地圖與依順序組合的 Google Maps 方案 A 路線；停留及行車估時手動填寫。
- 航班、租車、住宿、票券摘要與訂單連結；餐廳主選／備案、景點亮點可加入每日行程。
- 購買清單、行李清單、待辦事項，支援負責人與完成勾選。
- JPY/TWD 記帳、付款人、指定或全體均分、分類統計、預算餘額。手動匯率套用所有支出；概覽尚不處理旅伴還款。
- 每日天氣與道路確認欄位、冬季準備欄位、官方資訊連結、重要聯絡、旅行共用備註。
- 伺服器 SQLite 共用儲存；每 10 秒檢查旅伴更新。編輯表單時暫停刷新。版本衝突不覆蓋資料，提供草稿下載及載入最新版。

## 保存與後續修改

實際旅行資料在 data/trip.sqlite3；重啟程式不會清空。介面的「下載資料備份」匯出 JSON 供保留／後續填入，沒有一鍵匯入介面。完整復原請在停止伺服器後備份及還原整個 data/。data/access-key.txt 是存取金鑰，不應加入公開原始碼或分享專案壓縮檔。

public/index.html、style.css、app.js 是介面；server.py 是共用儲存。程式使用 Python 標準函式庫，不需要安裝額外套件。可繼續由這個專案填入資訊與修改介面。
