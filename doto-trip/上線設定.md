# 上線設定

狀態：已備妥部署檔案，尚未連接主機、尚未上線。

這個專案含有共同編輯與記帳資料，須部署網頁及 server.py，不能只把 public/ 上傳至靜態網頁服務。

## 主機所需設定

- 支援 Docker 或 Python 3.10 以上。
- 使用 HTTPS 網址，由主機的反向代理終止 TLS。
- 掛載永久儲存磁碟至 /data，並讓容器的 trip 使用者可讀寫。
- TRIP_DATA_DIR 設為 /data。
- TRIP_HOST 設為 0.0.0.0。
- PORT 依主機指定；預設 8765。
- TRIP_ACCESS_KEY 在主機的秘密設定中填入新的隨機分享金鑰，不要放入程式碼。公開網址使用 /#key=這個金鑰。請勿沿用已在聊天中出現的本機測試金鑰。
- 單一執行個體，共用同一份 SQLite 檔案；不要以多個各自存檔的執行個體部署。
- 反向代理傳給服務的 Host 須與使用者網址的 Origin 相符；否則儲存會被跨來源檢查拒絕。

Dockerfile 已包含启动設定。原始碼不含本機 data/ 或分享金鑰。資料將在 /data/trip.sqlite3 保存；重啟或更新程式时須保留此磁碟。

## 上線後驗收

1. 用完整 HTTPS 連結開啟，再用另一裝置開啟相同連結。
2. 新增一筆可清除的測試待辦，确认另一裝置顯示更新。
3. 重啟服務，确认資料仍存在。
4. 不帶分享金鑰讀取 /api/trip 應回覆 401。
5. 確認編輯版本衝突不覆蓋旅伴修改。
6. 刪除測試資料後才分享給旅伴。

目前冬季背景照片是外部來源連結，正式发布前須換成使用者照片或已授權圖片。公共主機前方應提供連線與請求大小限制；目前伺服器適合少量旅伴使用。

網站只包含旅行資料與網頁，不包含 ChatGPT 對話。
